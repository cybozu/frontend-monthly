### pnpm 12.4

- 共有者: @mugi_uno

9/10 に pnpm 12.4 がリリースされました。

- https://pnpm.io/blog/releases/12.4

ここでの大きい変更として、従来の npm パッケージに加えて、Python、Cargo (Rust) のパッケージもサポートされました。

pnpm-workspace.yaml に

```
cargo:
  enabled: true
python:
  enabled: true
```

などと書いておくだけで、 `pnpm add crate:serde` `pnpm add pypi:httpx` などとして依存パッケージをインストールできるようになります。

これに対して、「なぜ Rust と Python をサポートするのか？」という疑問が Discussion に起票されています。

- [Why Rust & Python package management? #14721](https://github.com/orgs/pnpm/discussions/14721)

[メンテナからの回答](https://github.com/orgs/pnpm/discussions/14721#discussioncomment-18365628)があり、要約すると次のような内容でした。

- コードの転送やバージョン管理に関係するものは全て pnpm の対象範囲
- そもそも pnpm の説明には長年 "Fast, disk space efficient package manager" とあるが、JavaScript/Node.js のパッケージマネージャとは明記されておらず、当初から計画されていたもの
  - JavaScript のパッケージ管理が一番難しかっただけ
- pnpm 自体が 12.4 で Rust に書き直されており、そこで使いたいのもある
- 現代では、リポジトリにフロントエンドに加えて多言語が混在することが一般的
- 将来的にはさらに多くの言語をサポートするかもしれない

正直私も pnpm = npm のパッケージマネージャという認識だったので「そうだったの！？」という感じでした。

複数言語の管理となると、[mise](https://mise.jdx.dev/) などが利用されるケースも多いですが、
pnpm が今後拡張されていくと、そのあたり単体でカバーされるようになるのかもしれませんね。

（ただ、"pnpm" と名前の一部に "npm" が入ってるのはいいのでしょうか）

### [Vitest 5.0 is out!](https://vitest.dev/blog/vitest-5.html)

- 共有者: @nus3

Vitest 5.0 がリリースされました。

5.0 ではパフォーマンス改善にフォーカスしていたようですが、そのほかにもいくつか新しい機能や変更があります。

#### パフォーマンス改善

- [vitest-dev/benchmarks](https://github.com/vitest-dev/benchmarks)というベンチマーク用のリポジトリを作った
  - Fable で作ったものを Vitest チームがレビューしたもの
  - シンプルな単体テストから 1300 モジュールあるプロジェクトまで、さまざまな条件でのベンチマークをしている
  - プールと環境を跨いで実行される
- このベンチマークの結果、以前のバージョンと比べ、15〜25%ほど実行時間が速くなった
- テスト実行時の内訳がパーセント表示されるように
  - `Duration  3.76s (environment 79%, import 13%, transform 6%, tests 1%, setup 1%)`
- `vitest doctor`コマンドで、他の設定時にどれくらいパフォーマンスが診断してくれるように

#### 機能追加や変更

- Trace View がビルトイン
  - Playwright など provider に依存せずとも使えるように
- 関数の引数ごとに異なる返り値を定義する`vi.when`が追加
- `clearMocks`がデフォルト true に
  - 次のテストにモックの呼び出しが引き継がれないように
  - 実行順序に依存する問題の原因の解決策
- Fake timers のモック対象に Temporal API も追加
- `--repeats`オプションが追加。結果に関わらず指定した回数だけテストを繰り返し実行する
