### [Deno is joining Cloudflare](https://deno.com/blog/cloudflare)

- 共有者: @nus3

Deno の開発チーム全員が Cloudflare に join することが発表されました。

- Deno ではアプリケーションの実行をシンプルにしたいと考えてて、それで Deno Deploy を作った
- Deno Deploy の運用を通して、アプリケーションをシンプルに実行するには複雑さがまだ残ってる
- だから[celld](https://celld.dev/)を開発した
  - celld はステートフルな分散システム
  - 自分の雑な理解だと、SQLite の DB を持つサーバーが 1 つのセル
    - 長期の永続化は s3 などのバケットにセルごとに保存
    - 別のセルに保存された情報を取得する際は、別セルへリクエストする
    - config や API は Cloudflare Workers に準拠
  - celld はアルファ版
- Cloudflare では m、Workers チームと Durable Objects チームと連携して開発進める

これに伴い、Deno の運用が変わります。

- Deno に関しては、1 年間のサポート後、開発を終了
  - 引き続き OSS なので、開発を継続したい人を歓迎するとのこと
- Deno Deploy は 6 ヶ月の運用継続後、終了
- JSR は継続。インフラを Cloudflare に移行
